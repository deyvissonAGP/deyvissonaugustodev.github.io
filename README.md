## 🌐 Deploy (GitHub Pages)

Este repositório está configurado para publicação automática via **GitHub Pages**.

Para ativar no seu fork:
1. Vá em **Settings → Pages**
2. Source: `Deploy from a branch`
3. Branch: `main` → pasta `/root`
4. Salve — em ~2 minutos o site estará online
